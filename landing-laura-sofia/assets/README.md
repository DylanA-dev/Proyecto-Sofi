# Assets — Nuestras fotos

Guarda aquí las 4 imágenes que mandaste:

- `holaa-20240902.jpg` ← [Image 1] Holaa 02/09/24 (con blur del número)
- `te-quiero-mucho-20240902.jpg` ← [Image 2] Te quiero mucho 6:33 (completa, sin recorte)
- `primer-te-amo-20240905.jpg` ← [Image 3] Primer te amo 05/09/24 (con blur del número)
- `fifo-bunnie-puffy-widgetable.jpg` ← [Image 4] Widgetable sofá verde

El script `scripts/blur_numero.py` blurea automáticamente la cabecera con `+57 322...` en las dos que tienen número.

Uso:
```
python scripts/blur_numero.py
```
Luego recarga `index.html` y verás las fotos en “Nuestras fotos” (grid 3→1, polaroid).
